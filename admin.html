Set up the dashboard

One-time setup on this device. Your GitHub token is encrypted with a password you choose and stored only in this browser.

How do I get a GitHub token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Name it Sketch Haven dashboard and pick an expiry (e.g. 1 year).
  3. Under Repository access choose Only select repositories and pick SketchHaven.github.io.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

How this dashboard works

Your website is a static site hosted on GitHub Pages. This dashboard edits one data file (data/site.json) and your uploaded photos by committing them to your GitHub repository. The website reads that file every time someone visits.

Publishing

Nothing changes on the live site until you press Publish changes. After publishing, GitHub Pages takes about 1–2 minutes to update, so refresh the site after a short wait.

Security

  • Only someone with your GitHub token can change the site. The password here just locks the token on this device.
  • The token is stored encrypted in this browser. Use Forgot password on the login screen to wipe it and set up again.
  • If your token ever leaks, delete it in GitHub → Settings → Developer settings and create a new one.
  • Tokens expire. If publishing says the token was rejected, create a new one and set up again.

Tips

  • Every publish is a normal Git commit, so you can always undo a mistake from the repository’s history.
  • Photos are saved as optimised JPEGs, so the site stays fast.
  • You can also add the Instagram username of a customer later: it arrives in the booking email.
